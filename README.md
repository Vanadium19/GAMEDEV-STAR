# 🏠 HOUSIT

2D платформер, созданный в рамках геймджема **Gamedev-Star**.

## 📖 Описание

Проект разработан за ограниченное время по теме геймджема. Игра демонстрирует простую механику перемещения и взаимодействия с игровым миром.

## ✨ Особенности
- Реализация механик платформера
- Анимация персонажа
- Zenject для управления зависимостями
- UniRX для связи модели с представлением
- UniTask для асинхронного взаимодействия
- Разработка в сжатые сроки для геймджема
